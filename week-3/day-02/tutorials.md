### Concepts to understand

- Typed arrays such as `number[]` and `string[]`
- The alternative `Array<number>` notation
- Arrays of arrays
- Function parameter types
- Function return types
- Optional parameters (`?`)
- Default parameters
- Rest parameters (`...values: number[]`)
- Typing anonymous functions
- Typing arrow functions
- Why a function's input and output types form a useful contract

Use the array and function techniques you already learned in JavaScript. The new task is to make their expected data explicit.
