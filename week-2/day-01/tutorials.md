## Objective

Become comfortable manipulating numeric and textual data instead of treating values as things that can only be printed or compared.

You should finish today able to clean, transform, and format basic input values.

### Concepts to understand

Numbers:

- `Number`
- `parseInt`
- `parseFloat`
- `toFixed`
- `Number.isInteger`
- `Number.isNaN`
- Basic `Math` methods
- Rounding numbers
- Generating a random number

Strings:

- `length`
- Accessing characters
- `trim`
- `toUpperCase`
- `toLowerCase`
- `charAt`
- `includes`
- `startsWith`
- `endsWith`
- `slice`
- `substring`
- `split`

You do **not** need to memorize every string method. Understand the common ones and know how to reason about using them.
