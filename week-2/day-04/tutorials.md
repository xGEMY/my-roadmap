### Concepts to understand

Higher-order functions:

- A function passed to another function
- `map`
- `filter`
- `reduce`
- `forEach`
- Choosing the right method for the job
- Transforming data without manually managing loop counters

GitHub:

- Remote repository
- Clone
- Push
- Pull
- Local vs remote history
- Keeping GitHub synchronized with your local project

### Important rule for today

Do **not** treat `map`, `filter`, and `reduce` as magic syntax.

Before writing one, be able to state the operation in plain language:

```text
map   → transform every item
filter → keep only matching items
reduce → combine many items into one result
forEach → perform an action for every item
```
