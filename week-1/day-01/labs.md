# Day 1 — Lab Exercises

## Lab — Level 1: Direct exercises

Write each solution yourself.

1. Print your name.
2. Print your age.
3. Create a variable for your name and print it.
4. Create variables for `medicineName`, `price`, and `isAvailable` and print them.
5. Print the type of each variable using `typeof`.
6. Create `quantity` and `price`, then calculate the total price.
7. Create `firstName` and `lastName`, then print the full name.
8. Rewrite the previous exercise using a template literal.

## Lab — Level 2: Apply the concepts

9. Create these variables:

```text
patientName
medicineName
quantity
unitPrice
```

Print one sentence such as:

```text
Ahmed bought 3 boxes of Panadol for a total of 150 EGP.
```

10. Create variables for a product's price and discount percentage. Calculate the final price.

11. Create variables for a patient's age, medicine price, and quantity. Print a readable purchase summary.

12. Convert a temperature from Celsius to Fahrenheit.

## Lab — Level 3: Challenge

### Pharmacy receipt

Given:

```text
customerName
medicineName
unitPrice
quantity
discountPercentage
```

Print:

```text
Customer: Ahmed
Medicine: Panadol
Quantity: 3
Subtotal: 150 EGP
Discount: 15 EGP
Final Total: 135 EGP
```

Do not copy the example above literally. Use variables and calculate the values.

## End-of-day self-test

Without looking at your notes, explain:

- What is a variable?
- Difference between `const` and `let`?
- What does `typeof` do?
- Difference between a string and a number?
- Why are template literals useful?
- How do you run a JavaScript file?

If you cannot explain these in your own words, review before Day 2.
