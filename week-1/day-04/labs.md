# Day 4 — Lab Exercises

## Lab — Level 1: Functions

1. Create a function that prints your name.
2. Create a function that receives two numbers and prints their sum.
3. Create a function that receives two numbers and returns their sum.
4. Create a function that calculates the area of a rectangle.
5. Create a function that checks whether a number is even.
6. Create a function that returns the larger of two numbers.
7. Create a function that calculates a discounted price.
8. Add a default discount value.

## Lab — Level 2: Functions + arrays

9. Create a function that receives an array of numbers and returns their sum.
10. Create a function that receives an array and returns its maximum value.
11. Create a function that counts a target value inside an array.
12. Create a function that prints every item in an array.

You should reuse loops from Day 3 inside these functions.

## Lab — Level 3: Objects

13. Create a `medicine` object with:

```text
name
price
quantity
isAvailable
```

14. Print each property.
15. Update the quantity.
16. Update the price.
17. Create a customer object.
18. Create a nested address object.
19. Create an array containing multiple medicine objects.

## Final self-test

Close your notes and answer these from memory:

1. What problem do functions solve?
2. What is the difference between a parameter and an argument?
3. Why would a function return a value instead of printing it?
4. What is an object?
5. What is a property?
6. How do you access an object's property?
7. How do arrays and objects differ?
8. How would you find one object inside an array without using `filter()`?
